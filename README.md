## Возможности

- **Скелетный 2D-рендерер (60 FPS)**: Высококачественный спрайтовый движок на HTML5 Canvas с поддержкой масштабирования без потери четкости (1.0x, 1.5x, 2.0x).
- **Синхронизация состояний агента в реальном времени**:
  - `idle` (арки улыбки) — режим покоя, плавное дыхание и парение.
  - `thinking` (фокусировка LED-экрана) — агент анализирует контекст или формирует план.
  - `running` (динамичный индикатор прогресса) — агент выполняет вызовы инструментов или редактирует файлы.
  - `needs_input` (янтарные вопросительные знаки) — агент ожидает ответа пользователя или разрешения на действие.
  - `ready` (золотые звезды) — задача успешно завершена, праздничная анимация.
  - `blocked` (красные крестики) — ошибка выполнения или отказ инструмента.
  - `sleeping` (закрытые глаза, индикация сна) — автоматический переход в спящий режим при неактивности.
  - `dragging` — динамический наклон и реакция на физику перетаскивания.
- **Прозрачный Always-On-Top оверлей**: Безрамочное окно Electron поверх всех окон с поддержкой многомониторных конфигураций и сквозного клика (Click-Through) вне активной зоны персонажа.
- **Интерактивный статус-бейдж**: Тултип над питомцем, отображающий текстовое описание текущего действия агента.
- **Быстрый фокус IDE**: Одинарный клик по питомцу моментально переключает системный фокус на окно Antigravity IDE.
- **HUD-меню управления**: Полупрозрачное меню по правому клику с возможностью переключения масштаба, ручного тестирования анимаций, отключения звука и скрытия окна.
- **Процедурный синтезатор (Web Audio API)**: Звуковые оповещения о смене статусов без внешних тяжелых аудиофайлов (с возможностью отключения звука).
- **Watchdog родительского процесса**: Автоматическое корректное завершение оверлея при закрытии или перезапуске процесса Antigravity.

```text
AG_Pet/
├── assets/             # Графические ассеты персонажа (части тела, спрайты)
```

## Руководство пользователя

### 1. Установка и подготовка окружения

Убедитесь, что на компьютере установлены **Node.js** (версии 18 или новее) и менеджер пакетов **npm**.

Клонируйте репозиторий и установите зависимости:

```bash
git clone https://github.com/lennielan/AG_Pet.git
cd AG_Pet

npm install
npm install --prefix desktop-overlay
npm install --prefix extension
```

Соберите TypeScript-код всех модулей:

```bash
npm run build
```

---

### 2. Запуск приложения

#### Вариант A. Автономный запуск оверлея на рабочем столе

Для запуска плавающего компаньона выполните:

```bash
npm start --prefix desktop-overlay
```

После старта в правом нижнем углу экрана появится Грави. Окно находится поверх других приложений, сохраняя прозрачный фон.

#### Вариант B. Запуск через расширение Antigravity IDE

Если скомпилированное расширение установлено в редакторе:
1. Запустите Antigravity IDE.
2. Расширение автоматически активируется при старте (`onStartupFinished`), запустит оверлей и начнет передавать актуальный статус из рабочей сессии.
3. Команды расширения в палитре (Ctrl+Shift+P):
   - `AG Pet: Toggle Floating Companion` — показать или скрыть питомца.
   - `AG Pet: Restart Companion` — перезапустить процесс оверлея.
   - `AG Pet: Focus Antigravity IDE` — вернуть фокус в редактор.

---

### 3. Взаимодействие и управление

- **Перемещение**: Зажмите левую кнопку мыши (ЛКМ) на Грави и перетащите его в любую удобную часть экрана. Позиция автоматически сохраняется в конфигурационном файле (`config.json`) и восстанавливается при следующем запуске.
- **Возврат в редактор**: Короткий клик ЛКМ по питомцу мгновенно переносит фокус в окно Antigravity IDE.
- **HUD-меню**: Нажмите правую кнопку мыши (ПКМ) по персонажу. Откроется интерфейс управления:
  - **SCALE**: переключение размера между `1.0x` (128px), `1.5x` (192px) и `2.0x` (256px).
  - **TEST STATE**: кнопки принудительного включения любого состояния (`Idle`, `Think`, `Running`, `Ready`, `Input`, `Blocked`, `Sleep`) для проверки анимаций и реакций.
  - **Sound ON / OFF**: включение или выключение звуковых сигналов.
  - **Hide Pet**: скрытие питомца.
- **Сквозной клик**: Зона вокруг персонажа прозрачна для курсора мыши и не блокирует взаимодействие с окнами за ней.

---

### 4. Автономный фоновый запуск (Windows)

В папке `scripts/` предусмотрены скрипты для запуска оверлея в виде фонового процесса:

- `scripts/ag-pet-service.js` — сервис, отслеживающий появление процесса Antigravity и автоматически поднимающий оверлей.
- Запуск сервиса:
  ```bash
  node scripts/ag-pet-service.js
  ```
